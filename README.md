# Shakespeare3D
Shakespeare3D is a virtual staging tool that lets the player act as the director of a Shakespearean drama. Make the scenes from Shakespeare's Romeo and Juliet your very own by staging where characters are positioned, deciding their actions or expressions, and determining how their lines should be performed.

The game includes a comprehensive tutorial that guides first-time players through the core directing mechanics.

## Download and Play
1. Download `Shakespeare3D.zip` from [Releases](https://github.com/aarngkk/Shakespeare3D/releases/tag/v1.0.0).
2. Extract the .zip file.
3. Run `Shakespeare3D.exe` (if Windows shows a security warning, click “More info”, then select “Run anyway”).
